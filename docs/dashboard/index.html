Data and method

The homepage and this dashboard use one compiled data model. Source post charts stay frozen. This page keeps all 42 aggregate language-score rows, 22 repeated stage-two observations, 26 explicitly unrun records, 594 V4 observer rows, timing histories and all 41 post tables. Later V4/V5 saves are separate additions. Repeated observations do not create new checkpoint identities.

Download the complete dashboard data (JSON) · Schema and update guide

Exact model-save times are unavailable in these sources. Observation and completion-verification times are retained under their own names. Different populations, tokenizer/scorer contracts, training clocks and timing denominators are never pooled. No private logs, source passages, model weights or live telemetry are fetched.
